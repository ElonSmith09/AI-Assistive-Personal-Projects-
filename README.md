# AI Assistive Personal Projects

Personal projects I built with help from ChatGPT, Codex, and other coding tools to address challenges in my own life.

## Projects

### [GRE Study Coach](./gre-study-coach)
A study tool with practice questions, lessons, and progress tracking. It helped me gain clarity and grasp GRE concepts more easily.

### [College Command Center](./college-command-center)
A dashboard for coursework, deadlines, and study progress. It helped me see everything in one place and understand material alongside the provided lesson plan.

### [Military Benefits Compass](./military-benefits-compass)
An Army-focused directory of military and veteran benefits, including education, employment, housing, recreation, and support programs. My personal setup includes recurring source checks; this repository contains a dated snapshot.

## How I built these

I identified the problems, chose the features, guided revisions, and evaluated how the tools worked for me. ChatGPT and Codex assisted with research, implementation, debugging, and documentation.

Each project folder includes setup instructions and current limitations. The college demo uses fictional coursework and grades.

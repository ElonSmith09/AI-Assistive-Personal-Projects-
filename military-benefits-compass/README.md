# Military Benefits Compass

Finding military benefits across scattered provider websites.

## Why I built it

I defined an Army-focused benefits directory to support my transition from military service and make useful programs easier to discover.

## What it does

Search and filter benefits, explore state gateways, save programs locally, and review provider requirements.

## My role and AI assistance

I identified the problem, chose the requirements, guided revisions, and evaluated the usefulness of the result. ChatGPT and Codex assisted with implementation, research, debugging, and documentation. This is an AI-assisted personal project; it does not represent entirely hand-written code.

## Technology

HTML, CSS, JavaScript, JSON.

## Run locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. This is a static research directory, not an eligibility determination. Data is a dated snapshot; no automatic updater is bundled. ID.me links go to providers and do not implement an ID.me login.

## Personal impact

Benefits Compass gives me a one-stop place to explore military and veteran benefits. My personal setup includes recurring source checks and updates, which help me keep track of changing opportunities. The GitHub copy is a dated snapshot; ongoing updates require a separately configured monitoring workflow.

## Portfolio privacy

This repository is a prepared portfolio copy. It excludes private deployment identities, account records and local databases. Sample data is labeled where applicable.

# College Command Center

Keeping coursework, deadlines, and practice in one place.

## Why I built it

I designed a dashboard around the practical challenge of organizing college work alongside other responsibilities.

## What it does

Track sample assignments, read lessons, practice questions, and follow a weekly study plan.

## My role and AI assistance

I identified the problem, chose the requirements, guided revisions, and evaluated the usefulness of the result. ChatGPT and Codex assisted with implementation, research, debugging, and documentation. This is an AI-assisted personal project; it does not represent entirely hand-written code.

## Technology

HTML, CSS, JavaScript, localStorage.

## Run locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. All coursework and grades in this repository are fictional. Browser storage is local to the device; there is no school account integration.

## Personal impact

The College Command Center gave me a view of everything in one place and helped me track my progress more clearly. It also gave me another way to understand the material alongside the provided lesson plan.

## Portfolio privacy

This repository is a prepared portfolio copy. It excludes private deployment identities, account records and local databases. Sample data is labeled where applicable.

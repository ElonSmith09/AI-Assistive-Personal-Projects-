# GRE Study Coach

Turning GRE preparation into a consistent, targeted routine.

## Why I built it

I created a study tool to organize GRE preparation and focus practice on skills that need more attention.

## What it does

Practice quantitative and verbal questions, read lessons, and track skill mastery and study time.

## My role and AI assistance

I identified the problem, chose the requirements, guided revisions, and evaluated the usefulness of the result. ChatGPT and Codex assisted with implementation, research, debugging, and documentation. This is an AI-assisted personal project; it does not represent entirely hand-written code.

## Technology

TypeScript, React, vinext, Vite, Cloudflare D1, Drizzle.

## Run locally

```sh
pnpm install
pnpm dev
```

Requires Node 22.13+ and pnpm. Follow the local URL printed by the dev server. Hosting requires a fresh deployment configuration and D1 setup. The progress API uses a single shared profile and lacks enforced per-user isolation: keep this a personal/local prototype until authentication, authorization and server-side scoring are implemented. Mastery is a heuristic, not a validated GRE score prediction. Not affiliated with ETS.

## Personal impact

The GRE Coach gave me more clarity during test preparation and made concepts easier to grasp. It helped me approach the material in a way that felt more understandable.
